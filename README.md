# 💸 PennyPulse - Expense Tracker App

Welcome to **PennyPulse**! An intuitive Android expense tracker app that helps users manage finances seamlessly. PennyPulse automatically tracks expenses and income through secure SMS scraping, so you can focus on your financial goals without manual entry. Built with a team effort to provide a smooth and efficient experience!

## ✨ Features
- **Secure Login & Signup**: User authentication with safe data handling.
- **Automatic Expense Tracking**: 
  - SMS scraping automatically identifies transaction amounts, types, and dates.
  - Securely fetches only necessary transaction information to ensure privacy.
- **Visual Insights**: Daily expenses presented with easy-to-read charts.
- **Manual Entry Option**: Users can manually add any transaction for flexibility.

## 🛠 Installation & Setup

1. **Clone the Repository**:
    ```bash
    git clone https://github.com/Ayush-Sakpal/pennypulse.git
    cd pennypulse
    ```

2. **Install Dependencies**:
    - **Frontend** (Kotlin Android dependencies): Open in Android Studio and sync project.
    - **Backend**:
      ```bash
      npm install
      ```

3. **Run the App**:
    - **Frontend**: Run the app on an Android emulator or connected device.
    - **Backend**:
      ```bash
      node server.js
      ```

> **Note**: Ensure PostgreSQL is installed and configured with your own database credentials.
